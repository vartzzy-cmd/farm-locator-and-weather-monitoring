About AgriSulbad

Supporting smarter agricultural location and weather monitoring.

What is AgriSulbad?

AgriSulbad is a web-based Land Farm Locator and Weather Monitoring project. It provides tools for users to locate places, identify farmland boundaries, calculate land area, and view weather conditions and forecasts.

Project Objectives

  • Help users locate selected places through an interactive map.
  • Allow users to mark and calculate farmland boundaries.
  • Provide current weather information for selected locations.
  • Display forecast information, including estimated rain probability.
